Rendere die Karte mit Testdaten und prüfe das Ergebnis visuell.

1. Führe `npm run check` aus.
2. Führe `npm run preview` aus (erzeugt `tools/out/breit.png`, `tools/out/kompakt.png` und
   `tools/out/kompakt-diagramme.png`).
3. Sieh dir alle Bilder an und beschreibe kurz, ob Ausrichtungen, Überlappungen, abgeschnittene Texte oder
   Leitungsanschlüsse auffallen. Gehe besonders auf den Bereich ein, den die letzte Änderung betrifft.
4. Falls Playwright nicht verfügbar ist, sage das ausdrücklich und prüfe stattdessen den Code.
